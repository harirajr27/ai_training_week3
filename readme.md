# AI & Machine Learning Assessment

This repository contains my solutions for all four tasks of the assessment:

- **[Task 1: Data Audit and Model Evaluation](./task1)** — Data cleaning (`46 -> 35` rows), majority baseline vs. TF-IDF + Logistic Regression, error analysis, and KMeans comparison.
- **[Task 2: Embeddings and Semantic Search](./task2)** — Sentence-transformer embeddings (`all-MiniLM-L6-v2`), NumPy cosine similarity, and keyword vs. semantic search comparison.
- **[Task 3: Tokens, Cost, Temperature, and Hallucination](./task3)** — `tiktoken` token analysis, monthly API cost estimation, temperature variation (`0.0` vs. `1.0`), and hallucination guardrails.
- **[Task 4: Decision Framework and Technical Proposal](./task4)** — 5-problem AI decision matrix, 1-page RAG proposal for contract Q&A, and 3-minute pitch.
